Simulateur de Réseau de Transports en Commun

il suffit d'executer gradle run pour lancer la simulation, une liste des commandes sera donné.

Public Transport System Simulator

Run "gradle run" to start a simulatuon, a list of commands will appear 

For the different tests already given, run "gradle build" to see all of them or run "gradle legacyTest*filename* to test a specific one
